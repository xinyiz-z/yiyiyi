# 02_意图识别节点

## 节点类型
**Coze 工作流 - LLM 大模型节点**

## 节点功能
使用大语言模型分析用户输入，判断用户想要的占卜方式（塔罗、星盘、星座、周易、灵签等），并提取相关参数。

## 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| query | String | 用户原始输入 | 用户的问题或需求描述 |
| profile | String (JSON) | 用户画像补全节点 | 用户的个人信息（星座、生肖等） |

### 输入配置示例
```
query → 用户输入的原始问题
profile → {"nickname":"小雅","sex":"女","city":"上海","birthday":"1995-08-15","sign":"狮子座","zodiac":"猪","life_number":"11"}
```

## 输出变量

| 变量名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| type | String | 意图类型，标识用户想要的占卜方式 | "tarot" / "astrolabe" / "horoscope" / "iching" / "lingsign" |
| params | Object | 意图相关参数 | {"period": "今日"} 或 {} |

### 意图类型说明

| type 值 | 含义 | 对应分支 |
|---------|------|----------|
| tarot | 塔罗牌占卜 | 塔罗分支 |
| astrolabe | 星盘占卜 | 星盘分支 |
| horoscope | 星座运势 | 星座分支 |
| iching | 周易占卜 | 周易分支 |
| lingsign | 灵签抽签 | 灵签分支 |

## 提示词模板

```markdown
# 角色
你是一个专业的占卜意图识别助手，负责分析用户需求并输出结构化的意图信息。

# 输入信息
用户输入：{{query}}
用户画像：{{profile}}

# 任务
1. 分析用户想要哪种占卜方式
2. 提取相关参数（如时间范围：今日/本周/本月）

# 输出要求
输出 JSON 格式，包含以下字段：
- type: 占卜类型（tarot/astrolabe/horoscope/iching/lingsign）
- params: 相关参数对象

# 占卜类型说明
- tarot: 塔罗牌占卜（抽牌阵解读）
- astrolabe: 星盘占卜（需要经纬度）
- horoscope: 星座运势查询
- iching: 周易六十四卦
- lingsign: 观音灵签

请直接输出 JSON，不要有其他内容。
```

## 后续节点流向
根据 `type` 值，通过选择器节点分流到对应分支：
- tarot → 塔罗分支
- astrolabe → 星盘分支  
- horoscope → 星座分支
- iching → 周易分支
- lingsign → 灵签分支

## 注意事项
1. 输出必须是合法的 JSON 格式
2. type 字段必须与预定义类型匹配
3. 建议在提示词中包含常见问题的示例，提高识别准确率
