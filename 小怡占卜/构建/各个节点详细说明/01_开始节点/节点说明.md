# 01_开始节点

## 节点类型
**Coze 工作流 - 开始节点**

## 节点功能
作为工作流的入口节点，接收用户输入的用户信息（生日、性别、昵称、所在城市）和占卜相关的问题。

## 输入变量

| 变量名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| birthday | String/Number | 是 | 用户生日，支持多种格式（详见下表） | "2004.11.22" / "农历1999年腊月廿三" |
| sex | String | 否 | 用户性别 | "男" / "女" |
| nickname | String | 否 | 用户昵称 | "小雅" |
| city | String | 否 | 用户所在城市 | "上海" |

### 生日格式支持

**阳历格式：**
- `2004.11.22` - 点分隔
- `2004年11月22号` / `2004年11月22日` - 年月日中文
- `2004/11/22` - 斜杠分隔
- `20041122` - 纯数字（8位）
- `1990` - 仅年份（精度降低）
- 时间戳（秒或毫秒）

**农历格式：**
- `农历2004年10月初八`
- `阴历2004.10.8`
- `农历2004-10-08`

## 输出变量
无（开始节点不产生输出变量，仅作为数据入口）

## 后续节点流向
- → 意图识别节点（分析用户想要哪种占卜方式）
- → 用户画像补全节点（补充用户信息）

## 注意事项
1. birthday 为必填项，若用户未提供应引导补充
2. city 可为空，但会影响星盘占卜的准确性（星盘需要经纬度）
3. 生日建议尽量精确到具体日期，仅提供年份时部分功能受限

## Coze 配置示例
```
输入变量配置：
├─ birthday: String/Number [必填]
├─ sex: String [可选]
├─ nickname: String [可选]
└─ city: String [可选]
```
