# 04_选择器节点

## 节点类型
**Coze 工作流 - 选择器节点**

## 节点功能
根据意图识别节点输出的 `type` 值，将工作流路由到对应的占卜分支。

## 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| 意图识别.type | String | 意图识别节点 | 识别出的占卜类型 |

## 条件配置

| 条件名称 | 判断式 | 连接到 |
|----------|--------|--------|
| 塔罗 | `意图识别.type == "tarot"` | get_taro_card 节点 |
| 星盘 | `意图识别.type == "astrolabe"` | 城市名改为经纬度节点 |
| 星座 | `意图识别.type == "horoscope"` | 星座知识库节点 |
| 周易 | `意图识别.type == "iching"` | 起卦代码节点 |
| 灵签 | `意图识别.type == "lingsign"` | 灵签知识库节点 |
| 默认 | （无匹配） | 塔罗分支（兜底） |

## 选择器配置示例（Coze 界面）

```
添加条件 1：
├─ 变量：意图识别 → type
├─ 运算符：等于
└─ 值：tarot（不加引号）

添加条件 2：
├─ 变量：意图识别 → type
├─ 运算符：等于
└─ 值：astrolabe

添加条件 3：
├─ 变量：意图识别 → type
├─ 运算符：等于
└─ 值：horoscope

添加条件 4：
├─ 变量：意图识别 → type
├─ 运算符：等于
└─ 值：iching

默认分支：
└─ 连接到塔罗分支（兜底）
```

## 注意事项
1. 各分支的**最后一个节点输出变量必须都叫 `raw_data`**（同名同类型）
2. 选择器一次只跑一条分支，`raw_data` 只被赋值一次
3. "解读大模型"只需引用一个 `raw_data` 就能通吃所有类型
4. 必须保留默认分支，防止 type 识别不出时整条工作流报错
5. 条件从上到下依次判断，建议把最常见的塔罗放最上面
