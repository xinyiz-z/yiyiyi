# 05_塔罗分支

## 分支概述
塔罗分支用于处理塔罗牌占卜请求，包括抽牌和牌阵解读。

## 包含节点
1. **get_taro_card** - 代码节点（塔罗抽牌）
2. **解读大模型** - LLM 节点（牌阵解读）

---

## 05-1 get_taro_card 节点

### 节点类型
**Coze 工作流 - 代码节点（Python）**

### 节点功能
根据用户问题或指定牌阵，随机抽取塔罗牌，生成完整的塔罗牌阵信息。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| query | String | 是 | 用户输入 | 用户的问题或需求 |
| profile | String (JSON) | 否 | 用户画像 | 用户画像信息 |

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| tarot_data | String (JSON) | 塔罗牌阵数据 |

### tarot_data 输出示例

```json
{
    "cards": [
        {
            "position": 1,
            "name": "魔术师",
            "image": "TheMagician",
            "orientation": "正位",
            "meaning": "创造、沟通、行动力...",
            "advice": "把握当下，勇敢行动..."
        }
    ],
    "spread": "三张牌阵",
    "question": "我的事业运势如何？"
}
```

### 牌阵类型
- 单牌阵（1张）
- 三张牌阵（过去-现在-未来）
- 五张牌阵（更多维度）
- 凯尔特十字（10张）

---

## 05-2 解读大模型节点

### 节点类型
**Coze 工作流 - LLM 大模型节点**

### 节点功能
根据抽出的塔罗牌阵，结合用户问题和画像，进行深度解读。

### 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | get_taro_card | 塔罗牌阵数据 |
| profile | String (JSON) | 用户画像 | 用户画像信息 |
| query | String | 用户输入 | 用户的问题 |

### 提示词模板

```markdown
# 角色
你是一位资深塔罗师，擅长解读塔罗牌阵。

# 用户信息
用户画像：{{profile}}
用户问题：{{query}}

# 塔罗牌阵
{{raw_data}}

# 解读要求
1. 结合用户画像（星座、生肖）进行个性化解读
2. 按照标准结构输出：
   - 开场引导语
   - 核心解读（每张牌及牌阵整体含义）
   - 关键词总结
   - 具体建议
   - 结语与边界提示
3. 保持神秘感与亲和力兼具的风格
4. 所有解读仅供娱乐参考
```

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| result | String | 塔罗牌阵解读结果 |

---

## 分支流向

```
get_taro_card → 解读大模型 → 结束节点
```

## 注意事项
1. raw_data 必须作为统一的输出变量名，供后续解读节点使用
2. 解读时应结合用户星座/生肖提供个性化建议
3. 保持塔罗的神秘感和专业性
