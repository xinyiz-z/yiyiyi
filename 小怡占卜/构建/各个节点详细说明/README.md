## 📋 节点类型说明

| 序号 | 节点名称 | 类型 | 输入 | 输出 |
|------|----------|------|------|------|
| 01 | 开始节点 | 工作流入口 | birthday, city, sex, nickname | - |
| 02 | 意图识别 | LLM | query, profile | type, params |
| 03 | 用户画像补全 | 代码(Python) | birthday, city... | profile (JSON) |
| 04 | 选择器 | 路由 | 意图识别.type | 分支路由 |
| 05 | 塔罗分支 | 代码+LLM | query | tarot_data |
| 06 | 星盘分支 | 代码+LLM | city, birthday | astrolabe_data |
| 07 | 星座分支 | 知识库+LLM | profile | horoscope_data |
| 08 | 周易分支 | 代码+知识库+LLM | query | iching_data |
| 09 | 灵签分支 | 代码+知识库+LLM | query | lingsign_data |
| 10 | 解读大模型 | LLM | raw_data | result |
| 11 | 结束节点 | 工作流出口 | result | 输出给用户 |

## 🔧 意图类型

| type 值 | 含义 | 对应分支 |
|---------|------|----------|
| tarot | 塔罗牌占卜 | 塔罗分支 |
| astrolabe | 星盘占卜 | 星盘分支 |
| horoscope | 星座运势 | 星座分支 |
| iching | 周易六十四卦 | 周易分支 |
| lingsign | 观音灵签 | 灵签分支 |

## 📝 统一输出规范

各分支的**最后一个节点**必须统一输出 `raw_data` 变量，供解读大模型节点使用。

### raw_data 示例

**塔罗**: `{"cards": [...], "spread": "三张牌阵", "question": "..."}`
**星盘**: `{"sun_sign": "狮子座", "planets": {...}, "aspects": [...]}`
**星座**: `## 处女座本周运势\n- 综合运势: ★★★★☆...`
**周易**: `{"hexagram": {...}, "changing": {...}, "question": "..."}`
**灵签**: `## 第42签 · 中签 · 行者得道\n- 签诗: ...`

## 📦 知识库

需上传至 Coze 的知识库文件（位于项目根目录）：
- `知识库_星座运势.md` - 12星座日/周/月运势
- `知识库_周易六十四卦.md` - 六十四卦详解
- `知识库_灵签抽签.md` - 100支灵签

## 🚀 快速开始

1. 在 Coze 平台创建工作流
2. 按节点顺序添加各节点
3. 配置输入输出变量（参考各节点说明.md）
4. 上传知识库文件
5. 配置 LLM 提示词
6. 测试并发布

## 📞 注意事项

1. 各分支最后节点统一输出 `raw_data`
2. 生日支持阳历/农历多种格式
3. 星盘需要城市经纬度
4. 解读结果需包含娱乐性质提醒
5. 建议将最常见的塔罗分支放在选择器最前面
