# 09_灵签分支

## 分支概述
灵签分支用于处理观音灵签抽签请求，包括随机抽签和签文解读。

## 包含节点
1. **灵签抽签代码节点** - 代码节点（随机抽签）
2. **灵签知识库节点** - 知识库查询（签文详解）
3. **解读大模型** - LLM 节点（签文解读）

---

## 09-1 灵签抽签代码节点

### 节点类型
**Coze 工作流 - 代码节点（Python）**

### 节点功能
随机抽取一支观音灵签（1-100号）。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| query | String | 是 | 用户输入 | 用户的心愿或问题 |
| profile | String (JSON) | 否 | 用户画像 | 用户画像信息 |

### 抽签逻辑
- 使用随机数生成 1-100 的签号
- 确保每次抽签的随机性

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| lingsign_basic | String (JSON) | 抽签基础信息 |

### lingsign_basic 输出示例

```json
{
    "number": 42,
    "level": "中签",
    "title": "行者得道",
    "question": "我的事业运如何？"
}
```

---

## 09-2 灵签知识库节点

### 节点类型
**Coze 工作流 - 知识库节点**

### 节点功能
从灵签知识库中检索对应签号的完整签文。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| 签号 | Number | 是 | 灵签抽签代码节点 | 抽中的签号（1-100） |

### 知识库内容
- **覆盖范围**：100支观音灵签
- **数据来源**：知识库_灵签抽签.md
- **上传方式**：将 md 文件整体导入 Coze 知识库

### 检索关键词
- 签号：如"第42签"、"第四十二签"
- 签文关键词：如"行者得道"

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| lingsign_detail | String | 完整签文 |

### lingsign_detail 输出示例

```markdown
## 第 42 签 · 中签 · 行者得道

- **签诗**：云散月明花弄影，凤皇飞入凤凰群。前途有路终须到，寄语行人早问津。
- **解签**：守得云开，方见月明。贵人相助，终有所成。
- **白话解读**：事业经历波折后终将顺利，适合坚持；感情先苦后甜；健康注意调理。
```

### 吉凶分布
- **上签（大吉）**：1、8、11、12、13、18、21、42、45、47、50、51、73、80、81、86、89、100
- **中签（平）**：其余各签
- **下签（小凶）**：2、7、24、26、40、54、70

## 09-3 解读大模型节点

### 节点类型
**Coze 工作流 - LLM 大模型节点**

### 节点功能
根据签文和用户心愿，进行个性化的签文解读。

### 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | 灵签数据合并 | 完整签文信息 |
| profile | String (JSON) | 用户画像 | 用户画像信息 |
| query | String | 用户输入 | 用户的心愿 |

### 提示词模板

```markdown
# 角色
你是一位精通观音灵签的解签师，擅长解读签文含义。

# 用户信息
用户画像：{{profile}}
用户心愿：{{query}}

# 签文数据
{{raw_data}}

# 解读要求
1. 先呈现签号、吉凶、签诗
2. 解读签诗的寓意
3. 结合用户心愿（如求事业、求感情、求健康）重点展开
4. 提供实用的行动建议
5. 保持温和、鼓励的语气
6. 结尾自然融入"心诚则灵，重在自省"的提示
7. 所有解读仅供娱乐参考
```

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| result | String | 签文解读结果 |

---

## 分支流向

```
灵签抽签代码 → 灵签知识库 → 解读大模型 → 结束节点
```

## 注意事项
1. 抽签代码和知识库查询结果合并后作为 raw_data 输出
2. 解读时应根据用户心愿（求什么）调整重点
3. 无论抽到何种签，都应保持积极正面的引导
4. 提醒用户：签文重在提醒与自省，命运掌握在自己手中
