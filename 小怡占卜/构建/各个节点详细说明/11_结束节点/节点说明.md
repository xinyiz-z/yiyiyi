# 11_结束节点

## 节点类型
**Coze 工作流 - 结束节点**

## 节点功能
作为工作流的终点，输出最终的占卜结果给用户，并引导用户进行后续互动。

## 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| result | String | 解读大模型节点 | 完整的占卜解读结果 |

## 输出内容

### 标准输出结构

```markdown
## 🌟 占卜结果

✨{{nickname}}✨ 的占卜报告

{{result}}

---

## 💬 还想继续探索吗？

🔮 **你可以这样问我：**
- 「帮我看看今天的财运」
- 「来一次塔罗牌占卜」
- 「抽支灵签看看」
- 「我的星盘有什么特点」

🌙 小怡随时在这里为你服务~
```

## 结束节点配置项

### Coze 配置界面

```
结束节点配置：
├─ 输出变量：
│   └─ result: String
│
└─ 回复内容：
    └─ 使用变量 {{result}}
```

### 变量引用

| 变量名 | 来源节点 | 说明 |
|--------|----------|------|
| result | 解读大模型节点 | 占卜解读结果 |
| profile | 用户画像补全节点 | 用户画像（可选） |

## 追问引导语模板

```
## 💬 还想继续探索吗？

🔮 **你可以这样问我：**

### 运势查询
- 「今天/本周/本月运势怎么样？」
- 「处女座本周事业运」

### 占卜类
- 「帮我占一卦看看」
- 「来一次塔罗牌占卜」
- 「抽支灵签」

### 分析类

- 「分析一下我的性格」

### 闲聊类
- 「给我讲个星座故事」
- 「什么是生命数字」

---

💡 **提示**：直接告诉我你想做什么，或者用上面的示例试试吧！

🌙 小怡随时在这里为你服务~
```

## 注意事项
1. 结束节点是工作流的唯一出口
2. result 变量包含完整的占卜解读内容
3. 追问引导语帮助用户继续使用智能体
4. 确保输出格式美观，阅读体验良好
5. 保持小怡的人设风格：温暖、专业、有趣
