# 07_星座分支

## 分支概述
星座分支用于查询用户星座的运势信息，支持日/周/月运势及爱情/事业/健康/综合等维度。

## 包含节点
1. **星座知识库节点** - 知识库查询（星座运势）
2. **解读大模型** - LLM 节点（运势解读）

---

## 07-1 星座知识库节点

### 节点类型
**Coze 工作流 - 知识库节点**

### 节点功能
从星座运势知识库中检索对应星座和时间范围的运势信息。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| 意图识别.params.period | String | 是 | 意图识别节点 | 时间范围：今日/本周/本月 |
| 意图识别.params.area | String | 否 | 意图识别节点 | 查询领域：爱情/事业/健康/综合 |
| profile | String (JSON) | 是 | 用户画像 | 用于确定用户星座 |

### 知识库内容
- **覆盖范围**：12星座 × 日/周/月 × 综合/爱情/事业/健康
- **数据来源**：知识库_星座运势.md
- **上传方式**：将 md 文件整体导入 Coze 知识库

### 知识库检索策略

```markdown
# 检索示例

用户：处女座本周事业运势如何？

检索内容：
1. 先定位星座："处女座"
2. 再定位时间："本周运势"
3. 提取对应领域的运势详情

# 检索关键词
- 星座名：如"处女座"、"天秤座"
- 时间词：如"今日运势"、"本周运势"、"本月运势"
- 领域词：如"爱情运势"、"事业运势"、"健康运势"
```

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| horoscope_data | String | 星座运势检索结果 |

### horoscope_data 输出示例

```markdown
## 处女座本周运势

- **综合运势**：★★★★☆  整体节奏偏快，机会多但也容易忙乱。周中可能收到一个意外好消息，周末适合独处充电。
- **爱情运势**：★★★☆☆  本周感情需要耐心，暧昧对象别逼太紧；伴侣间适合一起运动或冒险，重燃热情。
- **事业运势**：★★★★☆  有新项目或新合作机会，但细节容易出纰漏，重要文件务必复核。
- **健康运势**：★★★☆☆  精力旺盛但消耗也快，注意补水和睡眠，避免运动过量导致肌肉酸痛。
```

## 07-2 解读大模型节点

### 节点类型
**Coze 工作流 - LLM 大模型节点**

### 节点功能
根据检索到的星座运势，结合用户画像，进行个性化解读和总结。

### 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | 星座知识库节点 | 星座运势数据 |
| profile | String (JSON) | 用户画像 | 用户画像信息 |
| 意图识别.params | Object | 意图识别节点 | 查询参数 |

### 提示词模板

```markdown
# 角色
你是一位专业的星座分析师，擅长解读星座运势。

# 用户信息
用户画像：{{profile}}
查询时间：{{意图识别.params.period}}
查询领域：{{意图识别.params.area}}

# 运势数据
{{raw_data}}

# 解读要求
1. 根据用户星座和查询时间范围提供对应运势
2. 若用户询问特定领域（爱情/事业/健康），重点展开该部分
3. 若只问"运势怎样"，则综合解读四个维度
4. 结合用户其他信息（如性别、昵称）增加亲和力
5. 提供实用的行动建议
6. 结尾自然融入娱乐性质提醒
```

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| result | String | 星座运势解读结果 |

---

## 分支流向

```
星座知识库 → 解读大模型 → 结束节点
```

## 注意事项
1. 知识库节点直接输出原始运势数据
2. raw_data 必须作为统一的输出变量名
3. 若用户未指定时间范围，默认查询"今日运势"
4. 若用户未指定领域，提供综合运势解读
5. 知识库数据基于固定时间（可添加"当前日期"标注）
