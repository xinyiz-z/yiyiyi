# 08_周易分支

## 分支概述
周易分支用于处理六十四卦占卜请求，包括起卦和卦象解读。

## 包含节点
1. **起卦代码节点** - 代码节点（随机生成卦象）
2. **周易知识库节点** - 知识库查询（卦象详解）
3. **解读大模型** - LLM 节点（卦辞解读）

---

## 08-1 起卦代码节点

### 节点类型
**Coze 工作流 - 代码节点（Python）**

### 节点功能
通过随机方式生成周易六十四卦的卦象，包括本卦和变卦。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| query | String | 是 | 用户输入 | 用户的问题 |
| profile | String (JSON) | 否 | 用户画像 | 用户画像信息 |

### 起卦方式
- **数字起卦**：使用时间或随机数生成
- **硬币起卦**：模拟三枚硬币抛掷

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| iching_data | String (JSON) | 起卦结果 |

### iching_data 输出示例

```json
{
    "hexagram": {
        "name": "乾为天",
        "number": 1,
        "symbol": "☰☰",
        "judgement": "元亨利贞",
        "image": "天行健，君子以自强不息"
    },
    "changing": {
        "from": "乾为天",
        "to": "天风姤",
        "lines": [3]
    },
    "question": "我的事业发展如何？"
}
```

| 2 | 坤为地 | ☷☷ | 柔顺包容 |
| 3 | 水雷屯 | ☵☳ | 起始艰难 |

## 08-2 周易知识库节点

### 节点类型
**Coze 工作流 - 知识库节点**

### 节点功能
从周易六十四卦知识库中检索对应卦象的详细解释。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| 卦名 | String | 是 | 起卦代码节点 | 查询的卦象名称 |

### 知识库内容
- **覆盖范围**：六十四卦完整内容
- **数据来源**：知识库_周易六十四卦.md
- **上传方式**：将 md 文件整体导入 Coze 知识库

### 检索关键词
- 卦名：如"乾为天"、"坤为地"
- 卦序：如"第一卦"、"第三卦"
- 变卦：如"天风姤"（乾卦变卦）

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| iching_detail | String | 卦象详解 |

### iching_detail 输出示例

```markdown
# 乾为天（第一卦）

## 卦象
- **符号**：☰☰（六爻皆阳）
- **卦序**：第一卦
- **卦德**：刚健

## 卦辞
> 元亨利贞

## 彖传
大哉乾元，万物资始，乃统天。云行雨施，品物流形...

## 象传
> 天行健，君子以自强不息。

## 爻辞
- 初九：潜龙勿用
- 九二：见龙在田，利见大人
- 九三：君子终日乾乾，夕惕若厉，无咎
...

## 详解
乾卦象征天，寓意刚健有为...（更多解释见知识库原文）
```

## 08-3 解读大模型节点

### 节点类型
**Coze 工作流 - LLM 大模型节点**

### 节点功能
根据起卦结果和卦象详解，结合用户问题进行周易解读。

### 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | 起卦+知识库 | 周易数据 |
| profile | String (JSON) | 用户画像 | 用户画像信息 |
| query | String | 用户输入 | 用户的问题 |

### 提示词模板

```markdown
# 角色
你是一位精通易经的占卜师，擅长解读六爻卦象。

# 用户信息
用户画像：{{profile}}
用户问题：{{query}}

# 周易数据
{{raw_data}}

# 解读要求
1. 解读本卦卦辞和象传
2. 分析变卦含义（如有变化）
3. 重点关注动爻的解读
4. 结合用户问题给出具体建议
5. 保持易经的神秘感与智慧
6. 所有解读仅供娱乐参考
```

---

## 分支流向

```
起卦代码 → 周易知识库 → 解读大模型 → 结束节点
```

## 注意事项
1. 起卦和知识库查询的结果合并后作为 raw_data 输出
2. 变爻数量决定变卦情况
3. 周易解读需要一定专业知识，提示词要包含足够的背景信息
4. 若无变爻，则只解读本卦
