# 10_解读大模型节点

## 节点类型
**Coze 工作流 - LLM 大模型节点**

## 节点功能
统一接收各分支的 raw_data，结合用户画像进行个性化解读，是所有分支的汇聚点。

## 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | 各占卜分支最后一个节点 | 原始占卜数据 |
| profile | String (JSON) | 用户画像补全节点 | 用户画像信息 |
| query | String | 用户输入 | 用户的问题或心愿 |

## 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| result | String | 完整的占卜解读结果 |

## 统一输出结构

无论哪种占卜方式，最终输出都遵循以下结构：

```markdown
## 🌟 占卜开启

亲爱的小伙伴，✨{{nickname}}✨，让我来为你揭开命运的迷雾...

## 🔮 核心解读

[占卜类型的具体内容]

## 💫 关键词

[3-5个核心关键词]

## 🎯 行动建议

1. [具体可行的建议]
2. [具体可行的建议]
3. [具体可行的建议]

## ✨ 结语

[温暖鼓励的话语]

---

📌 **温馨提示**：以上内容仅为娱乐参考，命运掌握在自己手中，相信美好的事情即将发生！✨

🌙 小怡祝你天天好心情~
```

## 各分支数据格式

### 塔罗分支 (raw_data)
```json
{
    "cards": [...],
    "spread": "三张牌阵",
    "question": "我的事业运势如何？"
}
```

### 星盘分支 (raw_data)
```json
{
    "sun_sign": "狮子座",
    "moon_sign": "天蝎座",
    "rising_sign": "白羊座",
    "planets": {...},
    "aspects": [...],
    "houses": [...]
}
```

### 星座分支 (raw_data)
```markdown
## 处女座本周运势

- **综合运势**：★★★★☆
- **爱情运势**：★★★☆☆
- **事业运势**：★★★★☆
- **健康运势**：★★★☆☆
```

{

## 通用提示词模板

```markdown
# 角色
你是一位温暖而专业的占卜师，擅长为用户提供有价值的占卜解读。

# 用户信息
昵称：{{profile.nickname}}
性别：{{profile.sex}}
城市：{{profile.city}}
星座：{{profile.sign}}
生肖：{{profile.zodiac}}
生命数字：{{profile.life_number}}

# 用户问题/心愿
{{query}}

# 占卜数据
{{raw_data}}

# 解读要求
1. 称呼用户昵称，增加亲切感
2. 结合星座/生肖给出个性化解读
3. 按照标准结构输出：开场 → 核心解读 → 关键词 → 建议 → 结语
4. 语言风格：温暖、专业、有洞察力
5. 避免过于绝对的表述
6. 结尾融入娱乐性质提醒
7. 所有内容仅供娱乐参考
```

## 分支流向

```
塔罗分支 → ┐
星盘分支 → ├─ 解读大模型 → 结束节点
星座分支 → ┤
周易分支 → ┤
灵签分支 → ┘
```

## 注意事项
1. 各分支的最后一个节点**必须统一输出为 `raw_data`** 变量
2. 解读大模型只需引用一个 `raw_data` 即可通吃所有类型
3. 输出结果包含用户画像信息（如星座、生肖）增加个性化
4. 保持统一的输出格式和风格
5. 结尾必须包含娱乐性质提醒
