# 06_星盘分支

## 分支概述
星盘分支用于处理个人星盘分析请求，需要用户所在城市的经纬度信息。

## 包含节点
1. **城市名改为经纬度** - 代码节点（坐标转换）
2. **星盘计算节点** - 代码节点（星盘数据生成）
3. **解读大模型** - LLM 节点（星盘解读）

---

## 06-1 城市名改为经纬度节点

### 节点类型
**Coze 工作流 - 代码节点（Python）**

### 节点功能
将城市名称转换为对应的经纬度坐标，用于星盘计算。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| city | String | 是 | 用户画像 | 用户所在城市 |
| birthday | String | 是 | 用户画像 | 用户生日（YYYY-MM-DD） |

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| coordinates | String (JSON) | 经纬度坐标 |
| location_name | String | 标准化城市名称 |

### coordinates 输出示例

```json
{
    "latitude": 31.2304,
    "longitude": 121.4737,
    "city": "上海",
    "country": "中国"
}
```

### 内置城市列表
支持中国主要城市及全球重要城市，包括：
- 一线城市：北京、上海、广州、深圳
- 省会城市：成都、杭州、武汉、南京等
- 海外城市：纽约、东京、伦敦、巴黎等

### 误差处理
- 若城市不在列表中，使用该城市所在省份/国家的默认坐标
- 若完全无法识别，返回默认坐标（可指定）

## 06-2 星盘计算节点

### 节点类型
**Coze 工作流 - 代码节点（Python）**

### 节点功能
根据用户生日、时间和出生地经纬度，计算个人星盘数据。

### 输入变量

| 变量名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| birthday | String | 是 | 用户画像 | 用户生日（YYYY-MM-DD） |
| birth_time | String | 否 | 用户输入 | 出生时间（HH:MM） |
| coordinates | String (JSON) | 是 | 城市名改为经纬度 | 经纬度坐标 |

### 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| astrolabe_data | String (JSON) | 星盘数据 |

### astrolabe_data 输出示例

```json
{
    "sun_sign": "狮子座",
    "moon_sign": "天蝎座",
    "rising_sign": "白羊座",
    "planets": {
        "太阳": {"sign": "狮子座", "degree": 15},
        "月亮": {"sign": "天蝎座", "degree": 8},
        "水星": {"sign": "处女座", "degree": 22},
        "金星": {"sign": "巨蟹座", "degree": 5},
        "火星": {"sign": "天秤座", "degree": 18}
    },
    "aspects": [
        {"planet1": "太阳", "planet2": "月亮", "aspect": "三分相", "meaning": "和谐..."}
    ],
    "houses": [
        {"house": 1, "sign": "白羊座", "planets": ["火星"]}
    ]
}
```

## 06-3 解读大模型节点

### 节点类型
**Coze 工作流 - LLM 大模型节点**

### 节点功能
根据星盘数据，结合用户画像，进行全面的星盘解读。

### 输入变量

| 变量名 | 类型 | 来源 | 说明 |
|--------|------|------|------|
| raw_data | String | 星盘计算节点 | 星盘数据 |
| profile | String (JSON) | 用户画像 | 用户画像信息 |

### 提示词模板

```markdown
# 角色
你是一位专业占星师，擅长解读个人星盘。

# 用户信息
用户画像：{{profile}}

# 星盘数据
{{raw_data}}

# 解读要求
1. 解读太阳星座、月亮星座、上升星座的核心特质
2. 分析主要行星位置和相位
3. 提供性格分析、人际关系、事业方向等建议
4. 结合用户生肖（如有）提供更全面的解读
5. 保持专业且易于理解的风格
6. 所有解读仅供娱乐参考
```

---

## 分支流向

```
城市名改为经纬度 → 星盘计算 → 解读大模型 → 结束节点
```

## 注意事项
1. birth_time 为可选参数，若不提供则按中午12:00计算
2. 城市名改为经纬度节点是星盘分支的起点
3. raw_data 必须作为统一的输出变量名
4. 经纬度精度影响星盘准确性，建议引导用户提供精确出生地
