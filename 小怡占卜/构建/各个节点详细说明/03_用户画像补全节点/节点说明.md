# 03_用户画像补全节点

## 节点类型
**Coze 工作流 - 代码节点（Python）**

## 节点功能
接收用户的原始信息（生日、城市、性别、昵称），解析生日格式（支持阳历/农历），计算星座、生肖、生命数字，生成结构化的用户画像 JSON。

## 输入变量

| 变量名 | 类型 | 必填 | 来源节点 | 说明 |
|--------|------|------|----------|------|
| birthday | String/Number | 是 | 开始节点 | 用户生日 |
| city | String | 否 | 开始节点 | 用户城市 |
| sex | String | 否 | 开始节点 | 用户性别 |
| nickname | String | 否 | 开始节点 | 用户昵称 |
| calendar_type | String | 否 | 意图识别节点 | 历法类型："solar"（阳历）/"lunar"（农历）/"auto"（自动识别，默认） |

### 生日格式支持

**阳历：**
- `2004.11.22` / `2004年11月22号` / `2004/11/22` / `20041122`
- 时间戳（秒或毫秒）
- 仅年份：`2004` / `2005`（精度降低）

**农历：**
- `农历2004年10月初八` / `农历1999年腊月廿三`
- `阴历2004.10.8` / `阴历2000.2.2`

## 输出变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| profile | String (JSON) | 用户画像 JSON 字符串 |
| debug_params | String (JSON) | 调试参数（可选） |

### profile 输出示例

```json
{
    "nickname": "小雅",
    "sex": "女",
    "city": "上海",
    "birthday": "1995-08-15",
    "sign": "狮子座",
    "zodiac": "猪",
    "life_number": "11"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| nickname | String | 用户昵称（透传） |
| sex | String | 用户性别（透传） |
| city | String | 用户城市（透传） |
| birthday | String | 阳历生日，格式 YYYY-MM-DD（农历自动转换） |
| sign | String | 星座名称，如"狮子座" |
| zodiac | String | 生肖名称，如"猪" |
| life_number | String | 生命数字（1-9 或 11/22/33） |

## 核心算法

### 星座计算
根据阳历生日日期确定星座，返回格式如"狮子座"。

### 生肖计算
根据农历年份计算生肖，使用干支纪年法。

### 生命数字
将阳历生日各位数字相加后递归求和，最终得出1-9、11、22或33。

### 农历转阳历
内置1900-2100年农历数据，支持农历日期自动转换为阳历。

## 后续节点流向
- → 意图识别节点（提供用户画像参考）
- → 各占卜分支（用于个性化解读）

## 错误处理
- 若 birthday 格式无法识别，返回空字符串 birthday
- 若 calendar_type 包含非法值，自动使用"auto"模式
- 若 city/sex/nickname 为 None/null，转换为空字符串

## 注意事项
1. birthday 字段统一输出为阳历 YYYY-MM-DD 格式
2. 农历生日会自动转换为阳历后再计算星座/生肖
3. 输出为 JSON 字符串，下游节点需解析或直接传给大模型
